# Security Policy

Please do not disclose credentials, restricted dataset files, personal access
tokens, or private participant information in a public issue. Report a suspected
software vulnerability to the corresponding author by e-mail using the address
listed in the manuscript. Dataset-access questions should be directed to the
original SWaT data provider.

This research code is supplied without any claim of operational plant readiness.
Do not deploy it as a safety or security control without an independent risk
assessment and validation programme.
